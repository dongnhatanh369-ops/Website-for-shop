# Phase 4 — Tăng trưởng

**Trạng thái:** Chưa bắt đầu  
**Mục tiêu:** Tăng khả năng tìm thấy sản phẩm, chuyển đổi và giữ chân khách hàng.

## Phạm vi frontend

- [ ] Metadata riêng cho từng trang sản phẩm.
- [ ] Canonical URL, sitemap và structured data Product/Breadcrumb.
- [ ] Danh sách yêu thích và thông báo restock.
- [ ] Đánh giá sản phẩm, lịch sử mua và tài khoản thành viên.
- [ ] Trang blog/hướng dẫn lắp ráp, sưu tầm.
- [ ] Analytics có consent và không thu thập dữ liệu dư thừa.
- [ ] Tối ưu ảnh, font, bundle và Core Web Vitals.
- [ ] A/B test có giả thuyết, metric và thời hạn rõ ràng.

## Phạm vi backend/nội dung

- [ ] API đánh giá, yêu thích, restock và lịch sử mua hàng.
- [ ] Chống spam/gian lận đánh giá và thông báo.
- [ ] CMS hoặc quy trình xuất bản nội dung.
- [ ] Luồng đồng ý/rút lại consent và chính sách lưu dữ liệu.

## Chỉ số đề xuất

- Tỉ lệ xem sản phẩm → thêm giỏ.
- Tỉ lệ bắt đầu checkout → hoàn thành đơn.
- Search success rate và zero-result rate.
- LCP, INP và CLS theo Core Web Vitals.
- Tỉ lệ khách quay lại và đăng ký restock.

## Definition of Done

- [ ] SEO kỹ thuật không có lỗi nghiêm trọng.
- [ ] Core Web Vitals đạt ngưỡng tốt ở nhóm trang chính.
- [ ] Analytics và consent được kiểm thử.
- [ ] Tính năng tăng trưởng có dashboard đo lường kết quả.
